# 2.5 Cài đặt

## 2.5.1 Giới thiệu Ngôn ngữ lập trình (NNLT) và Công nghệ sử dụng
Hệ thống **Cửa hàng tiện lợi (Quick Commerce)** được xây dựng bằng sự kết hợp của các công nghệ hiện đại, đảm bảo hiệu năng cao và trải nghiệm người dùng tối ưu:

**1. Frontend (Giao diện người dùng):**
- **React (v18)**: Thư viện JavaScript mã nguồn mở để xây dựng giao diện người dùng. Sử dụng chức năng Virtual DOM giúp ứng dụng cập nhật nhanh chóng và hiệu quả.
- **TypeScript**: Phiên bản nâng cao của JavaScript, bổ sung "kiểm tra kiểu tĩnh" (static typing) giúp phát hiện lỗi từ lúc viết code thay vì lúc chạy.
- **Vite**: Công cụ build siêu tốc cho các ứng dụng web hiện đại (thay thế Webpack/Create React App).
- **TailwindCSS**: Framework CSS tiện ích (utility-first) giúp thiết kế giao diện nhanh chóng trực tiếp trên các thẻ HTML/JSX mà không cần viết các file CSS riêng biệt phức tạp.

**2. Backend (Máy chủ xử lý):**
- **Python (v3.10+)**: Ngôn ngữ lập trình phổ biến, dễ đọc và mạnh mẽ, rất phù hợp cho xử lý đa tiến trình và Data/AI.
- **FastAPI**: Framework web hiện đại, siêu nhanh (hiệu năng ngang ngửa NodeJS/Go) để xây dựng API với Python, hỗ trợ sẵn tính năng xác thực kiểu tĩnh bằng Pydantic và tự động tạo tài liệu API (Swagger UI).
- **SQLAlchemy (Async)**: Thư viện Object-Relational Mapping (ORM) của Python, cho phép thao tác với CSDL qua các class và object thay vì viết SQL tĩnh. Phiên bản Async giúp cải thiện hiệu ứng I/O.
- **Alembic**: Công cụ quản lý migration cho database SQLAlchemy.

**3. Database (Cơ sở dữ liệu):**
- **PostgreSQL**: Hệ quản trị cơ sở dữ liệu quan hệ mã nguồn mở mạnh mẽ và đáng tin cậy.

## 2.5.2 Chương trình

### Một số đoạn code tiêu biểu (Đánh giá code V1)

*(Bổ sung ảnh chụp màn hình code hoặc dán link github tại đây)*

**1. Khai báo mô hình CSDL (SQLAlchemy ORM - Python)**
Ví dụ bảng Products:
```python
from sqlalchemy import Column, Integer, String, Boolean, Numeric, ForeignKey
from sqlalchemy.orm import relationship
from backend.models.base import Base

class Product(Base):
    __tablename__ = "products"

    id = Column(Integer, primary_key=True, index=True)
    sku = Column(String, unique=True, index=True, nullable=False)
    name = Column(String, nullable=False)
    base_price = Column(Numeric(12, 2), nullable=False)
    sale_price = Column(Numeric(12, 2), nullable=True)
    category_id = Column(Integer, ForeignKey("categories.id"))
    
    category = relationship("Category", back_populates="products")
```

**2. Xây dựng API Đầu cuối (FastAPI Endpoint)**
```python
from fastapi import APIRouter, Depends, HTTPException
from sqlalchemy.orm import Session
from backend.api import deps
from backend.schemas import ProductResponse

router = APIRouter()

@router.get("/{product_id}", response_model=ProductResponse)
async def read_product(product_id: int, db: Session = Depends(deps.get_db)):
    product = db.query(Product).filter(Product.id == product_id).first()
    if product is None:
        raise HTTPException(status_code=404, detail="Product not found")
    return product
```

**3. Khai báo Component Frontend (React/TSX)**
```tsx
import React, { useEffect, useState } from 'react';
import apiClient from '../api/client';

export const ProductList = () => {
  const [products, setProducts] = useState([]);

  useEffect(() => {
    apiClient.get('/products')
      .then(response => setProducts(response.data))
      .catch(error => console.error("Error fetching products:", error));
  }, []);

  return (
    <div className="grid grid-cols-4 gap-4">
      {products.map(p => (
         <div key={p.id} className="p-4 border rounded shadow">
             <h3 className="text-lg font-bold">{p.name}</h3>
             <p className="text-red-500">{p.sale_price ?? p.base_price} VNĐ</p>
         </div>
      ))}
    </div>
  );
}
```
